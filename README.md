# 🤖 Hybrid AI Code Understanding System

An intelligent, context-aware repository analysis tool that acts as a local Senior Software Architect. This system blends the deep semantic reasoning of cloud-hosted foundation models with the speed and privacy of local LLMs to help developers navigate, audit, and understand complex codebases instantly.

## 🌟 Key Features

* **⚡ Hybrid AI Routing Engine:** Seamlessly switch between ultra-fast local inference (**Ollama**) and powerful cloud-based computation (**Hugging Face Router API**).
* **🧠 Global Context Awareness:** Automatically reads your repository's directory structure and injects relevant local code files into the prompt context.
* **🛠️ Deep Knowledge Base:** Uses **Llama 3.3 70B** as a cloud generalist for architectural reasoning and instruction following, alongside local code-specific models.
* **📁 Interactive Code Explorer:** Clickable UI file path references (e.g., `[test_repo/conduit/app.py]`) generated by the AI automatically display code contents in a dedicated preview panel.
* **🔒 Strict Token & Secret Protection:** Configured with strict environment isolation to ensure API keys are never leaked to production or source control.

---

## 🏗️ System Architecture

The application is built using a modern decoupled architecture:

1.  **Frontend (React + Vite + Tailwind CSS):** A sleek, dark-themed IDE-like workspace featuring a live file explorer sidebar, a central code preview component, and an interactive chat pane.
2.  **Backend (FastAPI + Python):** An asynchronous high-performance API server managing file I/O sanitization, repository mapping, context stitching, and streaming response generators using `ndjson`.

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v16 or higher)
* [Python](https://www.python.org/) (v3.9 or higher)
* [Ollama](https://ollama.com/) (For running local models)

### 1. Repository Setup & Virtual Environment

Clone the repository and navigate to the project root:

```bash
git clone [https://github.com/Vaish-999/AI-Code_understanding.git](https://github.com/Vaish-999/AI-Code_understanding.git)
cd "AI Code Understanding System Design"

# Set up and activate your Python virtual environment:
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
```

### 2. Backend Installation & Configuration
Install the required Python dependencies:
```bash
pip install -r requirements.txt
```

Create a .env file in the root folder of your project to securely hold your credentials:
```bash
HF_TOKEN=your_huggingface_api_token_here
```
Start your FastAPI server:

```bash
python backend/main.py
```
The backend service will initialize and run locally at http://localhost:8000.


### 3. Frontend Installation & Setup
Open a separate terminal window, navigate to your frontend directory, install the Node packages, and launch the Vite development server:

```bash
npm install
npm run dev
```

 Open your browser and navigate to the local URL provided by Vite (typically http://localhost:5173).
